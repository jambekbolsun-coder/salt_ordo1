## Логика

```text
Покупатель → Каталог → Товар → Корзина / WhatsApp
                         ↓
               FAQ-помощник справа

/admin → Авторизация → Товары / Категории / Чат-бот / Команда / Настройки
```

Каталог изначально пустой. Товары, категории, цены, скидки, фотографии и FAQ добавляются только из админ-панели.

## Приложение Salt Ordo Admin

Откройте `/admin/` по HTTPS. На странице входа доступна установка; после входа — раздел **Приложение**. Chrome/Edge показывают кнопку, когда браузер разрешает установку. На iPhone/iPad используйте Safari → «Поделиться» → «На экран “Домой”». Права сотрудника после установки не меняются.

- Отдельные HTML, manifest, идентификатор и иконки для админки. Область приложения и service worker: только `/admin/`. `/admin` перенаправляется на `/admin/`.
- В Cache Storage хранится **только** публичный `/admin-pwa/offline.html`. HTML кабинета, API, токены, файлы и данные сотрудников service worker не кэширует. Запросы Supabase используют `cache: no-store`.
- Вход хранится в `sessionStorage` окна (при запрете хранилища — в памяти), старый постоянный токен Supabase удаляется из `localStorage`. После закрытия окна может потребоваться повторный вход; восстановление сессии браузером зависит от ОС. На общем устройстве обязательно нажимайте «Выйти». Это не HttpOnly-cookie/BFF: защита от XSS остаётся обязательной.
- Выход очищает локальный токен даже без сети и перезапускает страницу. При отсутствии сети серверная ревокация не гарантируется; выданный access token живёт до своего срока истечения. Supabase RLS и проверки ролей остаются границей доступа к базе.
- Рабочие данные доступны онлайн. Автоматической очереди изменений и фоновой отправки нет. Для проверки офлайн откройте приложение онлайн, затем отключите сеть и перезагрузите. Должен появиться нейтральный экран без данных.
- Обновление worker ожидает закрытия всех окон приложения; принудительного `skipWaiting` и перезагрузки незаполненных форм нет. При изменении офлайн-документа повышайте `CACHE_NAME` в `public/admin/sw.js`.
- В Vercel заданы CSP для админки, запрет встраивания, `nosniff`, `no-store`, ограничения разрешений и `noindex`. При смене Supabase проекта обновите также `connect-src` в `vercel.json`. Не добавляйте `unsafe-eval` или `unsafe-inline` в `script-src`.

Сборка: `npm ci && npm run build`. Локальная проверка production PWA: `npm run preview` (localhost считается безопасным контекстом). Worker не регистрируется в dev-режиме. Проверки: `npm test`, `npm run lint`, `npm audit`.

Это облачный кабинет существующего бизнеса. Изоляция нескольких компаний, тарифы и биллинг не добавлены: для продажи общего SaaS нескольким организациям требуется отдельная модель организаций и проверяемые RLS-политики с `tenant_id`.
